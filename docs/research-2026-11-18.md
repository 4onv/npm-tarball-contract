# GitHub research for November 18, 2026

The America/Chicago window was **2026-11-18 06:00 UTC through 2026-11-19 06:00 UTC**, end exclusive. Repository and public issue counts were observed on November 19. GitHub Trending is rolling, so its November 19 appearance cannot establish a November 18 rank or star gain.

The November 19 rolling snapshot included [CLI-Anything](https://github.com/HKUDS/CLI-Anything), [Superpowers](https://github.com/obra/superpowers), and [Cursor plugins](https://github.com/cursor/plugins). That suggested a way to make existing developer infrastructure easier to use from scripts and assistants. All 19 tracked 4onv repos were tied at zero measured stars and forks, with no public issues or PRs. I favored a short demo and a workflow that could be validated against real release artifacts without a model, framework, or paid service. [GitHub Trending](https://github.com/trending)

I chose the tarball contract because there is a concrete missing-file report and a release workflow the portfolio already uses. Each of the five updates shipped on November 19 needed an archive check. This project turns that repeated check into an install-free command with a policy that maintainers own. The existing 4onv npm Fetch Audit concerns dependency source policy, while this tool checks the artifact produced at the other end of the build.

The November 18 npm commit is evidence of repository activity. The missing-file issue is a separate, earlier demand signal. Repository star totals are point-in-time observations; no day-over-day gains were inferred.
